3. How Geographic Screening Works

TasbihSol uses a privacy-preserving, on-device geographic screening mechanism to determine whether the user is located in a restricted jurisdiction. The screening process uses the following signals, in order of priority:

  1. SIM Operator MCC (Mobile Country Code): The Mobile Country Code from the device's SIM card operator, which indicates the country of the user's mobile network provider.
  2. Carrier Network MCC: The Mobile Country Code from the currently connected carrier network, which may differ from the SIM operator if the user is roaming.
  3. Device Locale: The device's configured locale/region setting, used as a fallback when SIM/carrier information is unavailable (e.g., Wi-Fi-only devices).
Privacy-Preserving Design: The geographic screening process is performed entirely on-device. No location data, MCC codes, carrier information, or locale settings are ever transmitted to any server, logged, stored remotely, or shared with any third party. The screening result is stored locally as a simple boolean (permitted/restricted) flag only.

4. Privacy-Preserving Design

We have designed the geographic screening mechanism with privacy as a core principle:

  • On-Device Processing: All screening logic executes locally on your device. No external service is consulted.
  • No Data Transmission: No location data, network information, or screening results are transmitted to any server.
  • No Logging: No logs of screening checks, location data, or carrier information are created or stored.
  • No Precise Location: The App does not use GPS, Wi-Fi triangulation, or IP geolocation. The ACCESS_COARSE_LOCATION permission is used solely to access carrier/network MCC information for region determination.
  • Minimal Data: Only a boolean result (permitted or restricted) is retained on the device. The underlying MCC codes and locale data are processed transiently and discarded.
